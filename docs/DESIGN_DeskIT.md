# DESIGN_DeskIT —— 总体架构与实现约束

## 1. 分层架构

```
┌─────────────────────────────────────────────────┐
│  DeskIT.App（WPF 界面层）                        │
│  启动页 / 采集与诊断视图 / 动作确认 / 记录与台账  │
└───────────────┬──────────────────┬──────────────┘
                │ 引用             │ 引用
┌───────────────▼──────────┐  ┌───▼──────────────────────────┐
│  DeskIT.Core（领域与规则）│  │  DeskIT.Windows（能力封装）   │
│  枚举 / 模型 / 纯函数规则 │  │  PowerShell5.1 / 介质探测 /   │
│  不依赖 Windows API       │  │  WMI·注册表·服务·事件日志 …   │
└──────────────────────────┘  └───────────────────────────────┘
```

- **App 界面层**：只负责展示与交互，业务判断下沉到 Core。
- **Core 领域与规则层**：枚举、模型与可单元测试的纯逻辑（风险、排序、结论推导、状态机），跨平台、无副作用。
- **Windows 能力封装层**：以接口隔离所有 Windows 相关操作，便于替换与测试；外部脚本文本化存放在 U 盘 `scripts/`、`actions/`。

## 2. U 盘目录与数据布局（PRD 8.2）

```
E:\DeskIT\
  DeskIT.exe            程序主体（自包含，无需目标机预装运行时）
  manifest.json         程序文件哈希清单，用于启动自检
  data\                 加密数据目录：台账、快照、会话、审计、日志
    ledger.db
    snapshots\
    sessions\
    audit\
    backup\
    operators.json      处理人（工号 + 姓名）登记与高级模式开关状态
  actions\              修复动作定义（名称、风险级别、需重启、前置条件、脚本入口；含自定义沉淀的动作）
  scripts\              诊断与修复脚本（PowerShell 5.1 兼容）
  packages\             软件安装包 + 描述文件（含哈希与静默参数）
  reports\              导出的报告与台账文件
```

约束：路径与文件名使用 ASCII；不使用需要管理员权限才能创建的目录；整个目录可整体复制到新介质继续使用。

## 3. 模块与依赖关系（M1–M9）

| 模块 | 说明 | 主要依赖 |
|------|------|----------|
| M1 便携启动与运行环境 | 自检、提权、只读回退 | Windows（提权/自检）、Core |
| M2 设备识别与信息采集 | 系统/硬件/软件/网络快照 | Windows（WMI 等） |
| M3 问题诊断 | 场景化诊断项，输出四态结论 | Core（诊断结论/状态机）、Windows |
| M4 修复动作库 | 声明式动作定义与执行器 | Core（风险/结果/排序）、Windows（PS 5.1） |
| M5 软件安装与卸载 | U 盘携带安装包与描述文件 | Windows、M4 执行器 |
| M6 账号与权限辅助 | 查询类辅助 | Windows |
| M7 记录与多机台账 | 单台账归并、会话记录、报告产出 | Core（模型/结论）、M8 |
| M8 介质安全与数据保护 | 加密、可写性探测、拔出保护 | Windows（介质探测）、Core |
| M9 受控自定义命令与动作沉淀 | 管理员 + 高级模式 + 逐条确认 + 强制记录 | M4、M7、M8 |

依赖方向自上而下，不存在循环依赖；Core 不反向依赖任何上层模块。

## 4. 实现约束要点

- **离线**：代码中不得存在任何出网调用；报告为自包含单文件（样式与字体内置）。
- **不写目标机持久数据**：仅读写 U 盘数据目录与目标机临时目录，退出时清理临时目录。
- **PowerShell 5.1**：所有脚本须在系统内置 5.1 下可运行，不依赖 7+。
- **加密不绑定机器**：主密码经 KDF 派生密钥做认证加密（AES-256-GCM 或等价强度），**不使用与单机绑定的系统凭据保护机制**（U 盘需跨机使用），不落明文。
- **只读安全回退**：无法提权时程序仍能以只读诊断模式提供价值，并如实呈现“无法提权”。
- **敏感信息**：仓库不提交证书私钥、签名口令或测试凭据。
