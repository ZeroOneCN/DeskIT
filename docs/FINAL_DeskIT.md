# FINAL_DeskIT —— 交付总结报告

## 1. 项目定位

DeskIT 是一款**免安装、单目录便携**的 Windows 桌面 IT 运维工具：程序放在 U 盘里，插到员工电脑上就地运行（WPF 界面），全程离线，所有数据写在 U 盘上，一支介质覆盖全部机器并归并为同一份台账。

## 4. 架构与关键实现

- **分层**：`DeskIT.Core`（领域模型 + 可单测纯规则，不依赖 Windows API）→ `DeskIT.Windows`（Interface 隔离的 Windows 能力封装）→ `DeskIT.App`（WPF 只负责展示与交互）。
- **声明式动作**：动作以 JSON 描述（`actions/*.json`）"做什么"，由统一执行器集中处理参数绑定、前置条件、超时/取消/输出截断、风险分级确认与备份审计；M5 的包操作、M9 的沉淀动作都转换为动作定义复用同一执行器。
- **双通道边界**：查询类（M2 采集、M3 诊断、M6 账号查询）全部只读；变更类一律走 M4 动作通道，自动获得二次确认与审计。
- **数据与安全**：`data\operators.json` 为明文介质头（介质标识、KDF 参数、校验值、高级模式、处理人、设置），其余数据文件经 AES-256-GCM 加密；台账与审计为**仅追加** NDJSON。
