## 1. 需要业务方确认的决策点

| 编号 | 事项 | 现状 | 需要确认的内容 |
|------|------|------|----------------|
| T1 | 未解决原因类别 | 已实现一组默认类别（需更换部件或联系厂商 / 需网络或服务器侧配合 / 需用户继续观察 / 权限或策略限制 / 需先备份数据 / 无法复现 / 其他） | 是否与公司报修分类口径一致，需否增删 |

| T3 | 高级模式沉淀动作的参数化 | 含 `{{ }}` 占位符的命令**拒绝沉淀**（会被 M4 误判为参数） | 是否需要在沉淀时支持手动声明参数 |
| T4 | 回退标识的人工修正 | 机器标识自动获得、不可手改 | 回退标识（主机名 + 首次采集时间）是否允许人工修正 |
| T5 | 脱敏范围 | 界面展示脱敏开关默认开启；自动产出报告固定脱敏、工号保留、姓名遮蔽 | 投屏/示教场景的默认值是否符合现场习惯 |

## 2. 上线前必须现场验证的事项

| 编号 | 事项 | 验证方法 |
|------|------|----------|
| V1 | 自包含单文件发布与清单自检 | `dotnet publish src\DeskIT.App\DeskIT.App.csproj -c Release -p:DeskITPortable=true -o .\artifacts\publish`，再执行 `tools\Generate-Manifest.ps1` 生成 `manifest.json`，确认程序自检通过 |
| V2 | 目标机首次初始化与解锁流程 | 在干净 Windows 10 1809+ / Windows 11（x64）上首次运行：初始化向导（主密码 + 处理人工号姓名 + 忘记不可恢复的二次确认）→ 重启后解锁 |
| V3 | 真实 U 盘拔出保护 | 会话执行中直接拔盘，确认：动作立即停止、已完成结果保留、会话标记“已中断”、重新插入解锁后出现“上次未正常结束”出口 |
| V4 | 加密数据的跨机读取 | 同一介质在另一台电脑解锁后能读出台账与报告；主密码错误时确认无法读取 |
| V5 | 中介质迁移 | 把 `data\` 整体复制到新介质后确认“已更换介质”提示出现且数据可用 |
| V6 | 安装包实测 | 把真实安装程序与描述文件（含 `sha256`）放入 `packages\`，验证校验通过/不匹配/缺失/未声明哈希四种拦截 |
| V7 | 修改为只读的介质 | 用写保护开关或只读介质验证：禁止执行动作与结束会话、允许只读诊断与查看 |
| V8 | 磁盘水位约束 | 介质可用空间低于阈值时确认禁止开始新会话、禁止开始安装类动作 |
| V9 | 残留清理 | 退出程序后确认目标机临时目录 `DeskIT\<runId>` 已删除；人为占用时确认界面明确提示路径 |
| V10 | 自定义命令副作用标注 | 执行一条会创建计划任务/服务的命令，确认界面与报告单列“自定义命令清单”并标注持久化变更 |
